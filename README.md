# REELMovies - Your Ultimate Cinematic Destination

A responsive React Single-Page Application (SPA) built for the Web Applications Programming and Engineering course (Milestone 1).

## Features
- **Movie Discovery:** Browse a curated list of 10 movies with posters, ratings, and genres.
- **Interactive Filtering:** Search for movies by title.
- **Sorting:** Sort movies by year (newest) or rating (highest).
- **Responsive Design:** Fully usable on desktop and mobile devices with mobile first technologies using tailwind.
- **Routing:** Includes Home, Discover, About, Login, and Register pages.

## Technologies Used
- React (Vite)
- React Router DOM
- Tailwind CSS
- JavaScript (ES6+)
