## Purpose of AI Usage
Generative AI was used as a development assistant to support the following tasks:
- **Code Explanation:** Explaining React concepts such as `useState`, props, destructuring, and the `map`, `filter`, and `sort` array methods.
- **Debugging & Troubleshooting:** Assisting with Git configuration issues (e.g., fixing commit author identity) and resolving React routing errors and when I uploaded the project on Render I had some routing issues.
- **UI/UX Styling:** Providing Tailwind CSS utility classes for responsive grid layouts, forms, and hover effects.
- **Documentation:** Helping format the `README.md` file and submission guidelines.

## Affected Files / Features
- `src/components/MovieCard.jsx`: AI provided the initial Tailwind CSS card layout structure.
- `src/components/Discover.jsx`: AI assisted in explaining and structuring the combined `filter()` and `sort()` logic.
- `src/components/About.jsx`, `Login.jsx`, `Register.jsx`: AI provided the initial JSX boilerplate and Tailwind styling for forms and static sections.
- `src/App.jsx`: AI assisted in setting up the React Router DOM structure.
- `README.md` & `AI-USE.md`: AI helped format the Markdown documentation.
